# Local core delivery 0.2

This increment connects the native UI to real device-local persistence and pure Java policy decisions. Profiles, rule create/update/delete, exact canonical destination matching, per-rule ports, active-profile persistence and a bounded decision-event count are implemented. No device network enforcement, VPN, sensor virtualization, aliases, cloud synchronization or hardware mesh is implemented or claimed. No new permissions or network dependencies are added. Datastar remains the planned web presentation layer, not a replacement for native Android services.

The runtime database is a new private app database aegis_local_v1.db. Four tables are active in this increment: profiles, app_state, network_policies and policy_events. The older 15/16-table files remain historical design inputs, not live migrations. There is no destructive migration from legacy schemas. Future domain expansion requires explicit versioned migrations. Emergency is a profile label, not a validated emergency bypass. User-entered package names are test inputs, not authenticated app attribution.

Acceptance on a test device: choose CUSTOM, add a DENY rule for com.example.app and example.test on port 443, evaluate it and see DENY; test port 80 and see default ALLOW; close/reopen and verify the selected profile and saved rule persist; delete the rule and see ALLOW on port 443. No packets are sent by this evaluation. Profile-isolated rules must not appear when another profile is selected. On PARANOID an unmatched request produces DENY as a decision only. Logs record POLICY_EVALUATION, never invented blocked packets, and keep only 100 rows.

JUnit source tests are included. Android compilation, lint, JUnit execution and lifecycle behavior must be validated by CI and on-device testing. Host SQLite checks exercise the same DDL but do not substitute for Android integration tests. Debug APK upgrades may fail if the previous debug signing key differs; inspect any install error before removing an existing app or its data. Production signing is a separate delivery gate.
